# EasyEQ / 电竞调音台 v1.0.1

发布日期：2026-10-29

## 新增

### 进入编辑时的曲线变形

以前点「左右」或「低音」，曲线是直接跳过去的。现在按三种情况各走一次变形：

- 没开「叠加低音修正」，进低音编辑：图上原本没有低音这条线，所以从 0 dB 平线长成低音曲线；
- 开了叠加，进左右编辑：合并曲线收成左右曲线；
- 开了叠加，进低音编辑：合并曲线换成低音曲线。

动画约 0.2 秒，鼠标一落下就收尾，不会拖慢跟手操作。退出编辑时也会从刚编辑完的形状长回合并曲线。

### 软件内一键更新

设置 → 关于软件 →「检查更新」现在会直接下载新版本、替换程序目录并自动重启，
不用再去 GitHub 发布页手动下载解压。

- 更新包是 `EasyEQ.zip`，用 .NET 自带解压，用户机器上不需要装 7-Zip；
- 有未保存的改动时会先问保存，不会带着草稿直接重启；
- 下载地址只接受 GitHub 域名，防止接口被篡改后把程序引到别处；
- 替换失败会写日志到 `%TEMP%\EasyEQ-update\apply-error.log`，并把原来的程序拉起来。

## 发布前检查（给上传的人）

1. Release 标题用 `V1.0.1`，tag 也用 `V1.0.1`（程序和 GitHub 的 tag 比对时不区分大小写）。
2. 两个资产都要传：
   - `EasyEQ.zip` —— 软件内更新用，**名字必须一字不差**，程序按这个名字找资产；
   - `EasyEQ.7z` —— 手动下载 / 首次安装用。
3. `EasyEQ.zip` 解压后根目录要直接是 `EasyEQ.exe`，不能套一层文件夹。
