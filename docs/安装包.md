# 发布包

2026-10-27 · 发布形态：自包含目录 + 7z 压缩包

> 原来做过 Inno Setup 安装器，但这台机器上连管理员权限都创建不出它的临时目录
> （`%TEMP%\is-xxx.tmp`，错误 5），装不了。改用 7z，双击解压即用，零依赖。

## 一条命令出包

```
publish.cmd
```

三步：

1. 清掉旧的 `dist\EasyEQ` 和 `dist\EasyEQ.7z`
2. `dotnet publish` 成自包含 win-x64（283 个文件、166MB，不含 pdb 和日志）
3. `7z a -t7z -mx=9` 压成 `dist\EasyEQ.7z`（约 48MB）

需要 7-Zip，脚本会检查 `C:\Program Files\7-Zip\7z.exe`。

## 玩家怎么用

1. 解压 `EasyEQ.7z` 到任意目录（建议 `%LOCALAPPDATA%\Programs\EasyEQ` 或 D 盘自己建一个）
2. 双击 `EasyEQ.exe`
3. 想要桌面图标：右键 `EasyEQ.exe` → 发送到 → 桌面快捷方式

解压出来必须是**整个文件夹**，不能只拖 `EasyEQ.exe` 出来——旁边那些 dll 和 `AutoEqData\` 是它的一部分。

## 为什么是自包含

`SelfContained=true`，.NET 10 运行时和 WPF 都打进了包里。玩家机器不需要装任何 .NET，解压就能跑。

代价是 166MB 解压后体积，压缩后 48MB。

## 运行时数据

程序自己的数据在 `%LOCALAPPDATA%\EasyEQ`，跟解压到哪无关：

| 文件 | 内容 |
|---|---|
| `ui-state.json` | 曲线、预设名、开关、窗口大小 |
| `peace.txt.bak` | 每次保存前备份 |
| `startup-report.txt` | 每次启动的环境快照 |

卸载 = 删掉解压出来的文件夹。想连设置一起清就再删掉 `%LOCALAPPDATA%\EasyEQ`。

## 管理员权限

`EasyEQ.exe` 的 manifest 是 `requireAdministrator`，双击会弹 UAC。这是必须的——它要写
`C:\Program Files\EqualizerAPO\config\peace.txt`。拒绝提权就起不来。

## 版本号

改这三处：

- `src\PeaceWpf\PeaceWpf.csproj` 的 `<Version>`
- `Directory.Build.props` 的 `<Version>`
- `docs\启动画面.md` 里提到的版本显示（如果改了关于面板）

## 换机器发布时

`publish.cmd` 只依赖 .NET SDK 10 和 7-Zip，两台都不需要联网下载额外东西（NuGet 包会还原）。

如果以后想做安装向导，Inno Setup 那条路需要先解决「创建临时目录被拒」的问题；
在正常 Windows 上它大概率是好的，只是这台机器不行。
