# 频谱链路基准

- 时间：2026-10-26 14:02:56
- 采样率：48000 Hz
- .NET：10.0.13 / Microsoft Windows NT 10.0.19045.0
- 处理器：20 逻辑核

## 1. 现状：SpectrumAnalyzer.Snapshot()（8192 点 / 96 带）

一次调用 = 窗口化 8192 点 + FFT + 96 带取峰 + 1/3 倍频程平滑 + 时间平滑 + Clone。

| 配置 | 平均 | P50 | P90 | P99 | 最大 |
|---|---:|---:|---:|---:|---:|
| 8192 / 96（现状） | 356.8 | 345.3 | 363.4 | 436.5 | 3311.7 |

- 30 fps 下 UI 线程占用（按 P50）：1.0%
- 60 fps 下 UI 线程占用（按 P50）：2.1%
- 30 fps 最差帧 P99 占用：1.3%

## 2. 加大 FFT 点数 / 带数的代价（同算法复刻）

时间窗 = FFT 点数 / 采样率；bin = 采样率 / FFT 点数。

| 配置 | 时间窗 | bin | 平均 | P50 | P90 | P99 | 最大 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 8192 / 96 | 170.7 ms | 5.86 Hz | 262.6 | 258.6 | 276.2 | 322.1 | 394.2 |
| 8192 / 192 | 170.7 ms | 5.86 Hz | 336.3 | 330.6 | 354.3 | 436.1 | 507.5 |
| 16384 / 192 | 341.3 ms | 2.93 Hz | 733.7 | 730.9 | 748.7 | 788.7 | 822.6 |
| 16384 / 256 | 341.3 ms | 2.93 Hz | 838.6 | 832.6 | 860.5 | 917.1 | 1044.4 |

复刻 8192/96 与生产版 P50 差：-25.1%（用来验证复刻可信度；表内其余行为复刻版）。

## 2.5 电平一致性（半幅 1 kHz 正弦，峰值带读数）

半幅正弦理论读数就是 -6.0 dB。带数变化不该改变它。

| 带数 | 峰值 dB |
|---:|---:|

| RenderTargetBitmap（含软件光栅化） | 9210.2 | 9199.5 | 9397.6 | 9565.8 | 9658.4 |

- 纯几何构建在 30 fps 下占 UI 线程：2.928%

- 第二行是 WPF 的软件光栅化路径，真实运行时由 D3D 合成，这行是上限而不是实测。

## 4. 结论

- 一帧 FFT（现状）P50 约 345 µs；纯 FFT 16384 点约 731 µs（整帧），32768 点纯 FFT 约 793 µs。
- 纯几何构建 P50 约 976 µs，对 30/60 fps 来说几乎为零。
- 判断：GPU 化不会改善这两项；真正的改动点是刷新节奏、时间窗和带数/点数取舍。
