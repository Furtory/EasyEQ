# S6 独立运行：把前端直接接到 EqualizerAPO

日期：2026-10-24
依据：`执行计划.md` 里的「甩开 Peace」。

## 一句话结论

程序不再需要 Peace。启动时不找进程、不藏窗口、不发 `WM_APP` 消息；
只跟 EqualizerAPO 的 config 目录打交道：读 `.peace` 预设、写 `.peace` 与 `peace.txt`，
再确认 `config.txt` 里有那行 `Include`。装了 Peace 的机器照常能用，不装也能跑。

## 为什么要这一步

之前程序里还留着三处对 Peace 的依赖，都是历史遗留：

| 位置 | 原来的作用 | 问题 |
|---|---|---|
| `PeaceClient` + `Win32PeaceTransport` | 找窗口、发消息、藏界面 | 没装或没开 Peace 时全部落空，代码白跑一趟 |
| `PeaceLauncher` | 找 `Peace64.exe`、必要时拉起来 | 程序并不需要它启动，留着只是噪音 |
| `Protocol/*` 六个文件 | 消息号、推子动作、返回码 | 保存改成写文件后已无人使用 |

另外有一个真正会让人踩空的洞：EqualizerAPO 只读 `config.txt`，
我们的 `peace.txt` 必须被它 `Include` 进去才会生效。这一行以前由 Peace 维护；
Peace 不在了，就得程序自己确认。

## 接上 APO 的唯一一道手续

界面上的表现：

- 找到 config 目录、`config.txt` 里已经有 `Include: peace.txt` → 什么都不显示，状态栏是正常的「已载入」。
- 找到目录、但没挂上 → 顶栏一行橙字「EqualizerAPO 还没加载 peace.txt（config.txt 里缺 Include），点右边接上」，
  旁边一个「接入 APO」按钮；状态栏也提醒一次。
- 找不到 config 目录 → 和以前一样：只能看本地缓存，不能保存。

点「接入 APO」之后：

1. 先把 `config.txt` 复制一份到 `%LOCALAPPDATA%\PeaceWpf\config.txt.<时间戳>.bak`；
2. 只往末尾追加一行 `Include: peace.txt`，原有内容一个字不动；
3. 文件带只读位就先清掉；
4. 成功后在状态栏写明备份路径。

不做自动挂载：`config.txt` 是整台机器的入口文件，动它得让人看见。

## 验证

- 构建：`dotnet build PeaceWpf.slnx -c Debug`，0 警告 0 错误。
- 自测：108 项全过。新增覆盖：`Include` 的识别（注释、别的文件、子目录、大小写）、
  追加时保留原内容、改前留备份、重复调用不再写第二行。
- 实机：把 `PEACEWPF_CONFIG_DIR` 指到一个只写了 `Preamp: -3 dB` 的空目录，
  启动后顶栏出现提示与按钮（`docs/shots/09-apo-warning.png`）；
  点一下之后 `config.txt` 变成两行，备份文件出现在 `%LOCALAPPDATA%\PeaceWpf\`，
  提示与按钮消失（`docs/shots/10-apo-connected.png`）。
- 真实安装没动过：`C:\Program Files\EqualizerAPO\config\config.txt` 本来就是
  `Include: peace.txt`，程序启动时判定为「已经接好」，不写任何东西。

## 和 Peace 的关系

- 不再需要安装 Peace，也不再需要它先启动。
- `.peace` 预设格式保留，装了 Peace 的机器照样能直接打开我们的预设。
- 但 Peace 如果还在跑，它改参数时仍会重写 `peace.txt`，把我们的内容冲掉。
  这是 S7 冲突检测要处理的事；在它做完之前，别两边同时调。

## 开发与自测

```powershell
$env:PEACEWPF_CONFIG_DIR = 'D:\tmp\apo-test\config'
dotnet run --project src\PeaceWpf
```

这样界面读写的是那个目录，真实 `C:\Program Files\EqualizerAPO\config` 不会被碰。

## 已知限制

1. 只认 `Include:` 一行；APO 的 `Include:` 支持子目录，这里比到最后一段文件名。
2. `config.txt` 被别的程序改回原样时，界面上要重新点一次「接入 APO」（或重启时再看）。
3. 没有实现「卸载」：想让 APO 不理我们，手动删掉那一行 `Include` 即可。
